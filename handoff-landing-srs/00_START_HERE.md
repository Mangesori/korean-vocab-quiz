## 확정된 결정

1. **모바일 퀴즈 화면** — 페이지 배경을 흰색으로. 카드는 계속 걷은 채로 (7b)
2. **히어로 목업 데스크탑** — 앱 창 크롬, 사이드바 없음, 본문 641px (2a)
3. **히어로 목업 모바일** — 폰 프레임 없음, 창 358×560px, 안쪽 스크롤 (6a)
4. **오늘의 복습** — 목록을 접고 시작 버튼을 먼저 (5a)
5. **나만의 단어장** — 복습 단계·다음 복습 열 추가, 목록 행으로 (5c)
6. **라이브러리 복사** — 버튼이 "내 퀴즈에서 열기"로 변신(B) + 배정 다이얼로그(C)
7. **라이브러리와 내 퀴즈는 합치지 않는다** — 목적이 다름. 컴포넌트만 공유

## 적용 순서

```
01 토큰·폰트          ← 기계적, 먼저 해야 뒤가 안 꼬임
02 모바일 퀴즈 배경    ← 작고 효과 큼. 7개 스테이지 + QuizTake
03 + 04 히어로 목업    ← 가장 큼 (1,325줄)
05 학생 SRS           ← 5a는 새 쿼리 2개 필요
06 라이브러리 복사     ← RPC 반환값 수정이 선행
```

01→02는 이어서 하는 게 좋습니다(같은 파일들을 만짐). 03~06은 서로 독립입니다.
