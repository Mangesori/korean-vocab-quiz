## 5a · 오늘의 복습 — 시작이 먼저

### 지금

큰 숫자 + 지남 안내 + 밀림 경고 + **`max-h-72` 스크롤 목록(최대 20줄)** + CTA 순서입니다.
시작 버튼 앞에 스크롤 목록이 서 있어서, 매일 오는 화면에서 매일 스크롤을 지나야 합니다.

그리고 문제가 둘 더 있습니다.

- 목록 하단에 *"N개는 쓸 문장이 없어 이번엔 빠져요"*가 나오는데, 줄 배지와 **중복**이고 배지만 보면 포함되는 것처럼 읽힙니다
- 상단 부제가 *"1일 · 3일 · 7일 · 16일 · 35일 · 90일 간격으로…"* — 매일 오는 화면의 고정 자리에 **시스템 설명**이 박혀 있습니다

### 개편

```
오늘의 복습
어제 15개를 끝냈어요. 이어서 6일째입니다.        ← 부제 교체

┌──────────────────────────────────────────┐
│  18 개 준비됐어요          [주간 막대 6개]  │
│  이 중 4개는 예정일이 지났어요.              │
│                                          │
│  [ 복습 시작하기 (16개) → ]                │  ← 스크롤 없이 첫 화면
│                                          │
│  ⚠ 밀린 복습 31개는 하루 20개씩 나눠서…     │
│  ─────────────────────────────────────   │
│  오늘 나올 단어 보기   18개 · 2개는 문장이   │  ← 접힌 한 줄
│                       없어 빠져요      ⌄   │
└──────────────────────────────────────────┘

📖 나만의 단어장에서 전체 단어 보기 →           ← 두 페이지 연결
```

- 20줄 목록을 **접힌 한 줄**로 내리고, 그 줄이 "문장 없어 빠지는 개수"까지 말해서 하단 중복 문구가 사라집니다
- 부제 자리에 **어제 실적과 연속 일수** — 매일 달라지는 정보
- 오른쪽 주간 막대는 요일별 복습량, 오늘만 진한 초록

### ⚠ 새 쿼리 두 개가 필요합니다

현재 `get_due_review_items`가 주는 건 오늘 치 목록뿐입니다 —
`word · stage · due_at · overdue_days · level · slot · sentence · answer · hint · translation · meaning · sentence_from`

**"어제 15개를 끝냈어요 · 6일째"와 주간 막대는 여기서 나오지 않습니다.**

1. 날짜별 완료 이력 (최근 7일) — 주간 막대용
2. 연속 일수 (streak) — 부제용

둘 다 없으면 부제는 "18개 준비됐어요 · 16개를 풀 수 있어요" 같은 정적 문구로 대체하고 주간 막대를 생략할 수 있습니다. 나머지 구조는 그대로 갑니다.

## 5c · 나만의 단어장

### 지금

`max-w-6xl`에 `md:grid-cols-2` 카드입니다. 단어 하나 담기에 카드가 너무 넓고, 정렬이 없고(검색·즐겨찾기만), **삭제 버튼이 늘 떠 있습니다.**

### 개편 — 목록 행 + 복습 단계

```
나만의 단어장                                    [+ 단어 추가]
저장한 단어 142개 · 복습 중 96개 · 졸업 24개

[🔍 검색...] [★ 즐겨찾기] [복습 단계 전체 ⌄] [최근 추가순 ⌄]

┌─────────┬──────────────────┬─────────┬──────────┬────┐
│ 단어     │ 뜻 · 예문         │ 복습 단계 │ 다음 복습 │    │
├─────────┼──────────────────┼─────────┼──────────┼────┤
│ ★ 가깝다 │ close by          │ 7일차    │ 6일 지남  │ ✏🗑│
│         │ 우리 집은 학교에서… │         │          │    │
│ ☆ 어머니 │ mother            │ 90일차   │ 오늘      │ ✏🗑│
│ ☆ 리포트 │ report            │ 1일차    │ —        │ ✏🗑│
│         │ ⓘ 예문이 없어…     │         │          │    │
│ ☆ 치마   │ skirt             │ 졸업     │ 마스터    │ ✏🗑│
└─────────┴──────────────────┴─────────┴──────────┴────┘
```

열 폭: `168px | minmax(0,1fr) | 96px | 108px | 76px`, gap 14px

- **복습 단계 · 다음 복습 열 추가** — 가장 큰 변화. 단어장과 복습 일정이 이어집니다
- 90일차·졸업은 `#DCF0E4`/`#1F6B48`, 나머지는 `#F4F0EA`/`#6B635E`
- 지남은 `#B4831C`
- 즐겨찾기는 별 아이콘 하나로 왼쪽에 붙임
- **수정·삭제는 평소 `opacity: 0.4`, 호버 시 진해짐** — 지금은 삭제가 즐겨찾기와 같은 무게
- 예문 없는 단어는 그 자리에서 "복습에서 빠지는" 이유를 말해서 복습 화면의 안내와 원인이 이어짐
- 정렬 4종: 최근 추가순 · 단계순 · 가나다 · 다음 복습 임박순

### 데이터

`due_at`은 있지만 **단어장 쿼리(`vocabulary`)와 복습 진행 테이블을 조인해야** 합니다. 5c의 유일한 데이터 작업입니다.

---

## 폐기한 안

**5b 목록이 주인공** — 목록을 남기고 지남/예정으로 묶는 안. 기존 데이터만으로 되는 장점이 있었지만, 시작 버튼이 여전히 목록 뒤에 섰습니다.

다만 5b에서 나온 것 하나는 5a에도 적용하세요: 줄 배지의 `N/6단계`를 **실제 라벨**(`7일차`·`90일차`)로 바꾸는 것. `SRS_STAGE_LABELS`에 이미 있는 값이고 학생에게 뜻이 통합니다.
