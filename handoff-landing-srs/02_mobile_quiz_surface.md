# 02 · 모바일 퀴즈 화면 배경 전환 (7b)

**시안**: `모바일 퀴즈 배경 3안.dc.html` → `7b`

---

## 문제

페이지 배경 `#F9F7F4`와 프롬프트 패널 `#FAF8F5`가 거의 같은 색입니다.

데스크탑에서는 그 사이에 흰 카드가 끼어 있어 `흰 카드 위의 베이지 패널`로 읽힙니다.
모바일에서 카드를 걷으니(`bg-transparent sm:bg-white`) 패널이 같은 베이지 위에 앉아 **그릇이 사라집니다.**

### 묻히는 표면이 셋입니다

| 요소 | 색 | 상태 |
|---|---|---|
| 프롬프트 패널 | `#FAF8F5` | 배경(`#F9F7F4`)과 거의 같음 |
| 진행 바 트랙 | `bg-secondary` = `#F9F7F4` | 배경과 **동일** — 안 채워진 부분이 완전히 묻힘 |
| 문항 카운터 알약 | `#F4F0EA` | 약하게 보임 |

진행 바가 가장 심합니다. 초록 막대만 떠 있고 "얼마나 남았나"가 안 읽힙니다.

부수 효과로 **뜻과 입력칸의 위계가 뒤집힙니다** — 뜻은 그릇이 사라졌는데 입력칸은 테두리가 있어서 살아남습니다.

---

## 해결 — 모바일 페이지 배경을 흰색으로

표면 관계만 뒤집습니다.

| | 페이지 | 카드 | 패널 |
|---|---|---|---|
| 모바일 | **흰색** | 없음 | 베이지 `#FAF8F5` |
| 데스크탑 | 베이지 `#F9F7F4` | 흰색 | 베이지 `#FAF8F5` |

**새 색을 만들지 않습니다.** 있는 흰색과 있는 베이지의 역할만 바꿉니다.
배경값 하나로 세 표면이 다 살아납니다.

### 폐기한 안

- **7a 흰 카드 되살리기** — 진행 바·카운터가 카드 밖이라 절반만 고침. 걷어낸 결정을 되돌리는 값까지 치름. 내용 폭 324px로 축소
- **7c 패널을 진하게** — 톤은 좋지만 같은 패널이 폭에 따라 색이 달라지고, 브레이크포인트별 예외가 셋으로 늘어남

---

## 적용

### 1. 퀴즈 화면 페이지 배경

`src/pages/QuizTake.tsx` — 최상위 컨테이너에

```
bg-white sm:bg-background
```

`AppLayout` 전체를 바꾸면 안 됩니다. 다른 페이지(대시보드·목록)는 카드를 쓰므로 베이지 배경이 맞습니다.
퀴즈 화면만 예외입니다.

`/quiz/:id/take` 외에 `/review`도 같은 스테이지 컴포넌트를 쓰면 같이 적용하세요.

### 2. 진행 바 트랙

`bg-secondary`가 `--background`와 같아서 안 보입니다. 트랙에 명시적인 색을 줍니다.

```tsx
<Progress value={pct} className="[&_[data-slot=track]]:bg-[#F4F0EA]" />
```

또는 `Progress`를 감싼 wrapper에 `bg-[#F4F0EA] rounded-full overflow-hidden`.

⚠ `src/components/ui/progress.tsx`의 `bg-secondary`를 **직접 바꾸지 마세요** — shadcn 컴포넌트라 다른 곳에도 영향이 갑니다. 호출부에서 덮으세요.

### 3. 이전 버튼

`bg-white/50`이 흰 배경에서 안 보입니다.

```
bg-[#FAF8F5] sm:bg-white/50
```

`box-shadow`도 흰 배경에서는 의미가 없으니 모바일에서는 걷어도 됩니다.

### 4. 카드는 그대로 걷은 채로

7개 스테이지의 `border-0 sm:border shadow-none sm:shadow-sm rounded-none sm:rounded-2xl bg-transparent sm:bg-white`는 **건드리지 않습니다.** 이 결정이 7b의 전제입니다.

빈칸 채우기(`FillBlankStage.tsx`)만 `border shadow-sm bg-white`에 `sm:` 변형이 없어서 모바일에도 카드가 남습니다. 흰 페이지 위의 흰 카드가 되므로, 이 스테이지도 다른 스테이지와 같은 패턴으로 맞추는 게 좋습니다.

## 확인

- 진행 바에서 남은 분량이 보이는지 (가장 중요)
- 뜻 패널이 그릇으로 읽히는지
- 이전 버튼이 보이는지
- 데스크탑(`sm:` 이상)은 아무것도 변하지 않았는지
