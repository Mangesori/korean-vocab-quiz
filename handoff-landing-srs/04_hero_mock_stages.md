**시안**: `히어로 목업 7개 탭.dc.html` → `4a`~`4e`(데스크탑) · `4f`(모바일 5종)

---

## 결론 먼저

**7개 스테이지 전부 구조 변경 없음.**

학생 퀴즈 화면은 모두 `max-w-3xl`/`max-w-5xl mx-auto` **세로 스택**이고, `md:grid-cols-2` 같은 좌우 분할은 어디에도 없습니다.
데스크탑·모바일 차이는 **레이아웃이 아니라 폭·여백·글자 크기**입니다.

> 이전 시안에서 좌우 배치안(단어 카드 왼쪽 / 입력칸 오른쪽 등)을 그렸다가 폐기했습니다. 실제 코드에 없는 구조였습니다.

## 탭별 표

| 탭 | 카드 폭 | 모바일에서 달라지는 것 |
|---|---|---|
| 퀴즈 생성 (교사) | — | 유형 카드 2열 → 1열 세로 |
| 짝 맞추기 | `max-w-3xl` | 타일 `min-h-[3rem]`(48px), 단어 `text-sm`, `gap-3` |
| 단어 받아쓰기 | `max-w-5xl` | 패널 `p-6`, 뜻 `text-xl`. 입력칸은 `h-14 text-xl` 고정 |
| 빈칸 채우기 | `max-w-5xl` | **카드 크롬이 남는 유일한 탭** (`border shadow-sm bg-white`에 `sm:` 없음) |

## 모바일 공통 규칙

거의 모든 스테이지가 카드 껍데기를 벗습니다.

```
border-0 sm:border  shadow-none sm:shadow-sm  rounded-none sm:rounded-2xl
bg-transparent sm:bg-white       p-0 sm:p-6 md:p-8
```

내용이 화면 끝까지 붙습니다. **빈칸 채우기만 예외.**

## 하단 내비게이션

3열 그리드입니다. 가운데는 `skipButton` 슬롯.

- **`모르겠어요`는 실제로 렌더됩니다** — 받아쓰기·문장 순서·문장 만들기에서 스테이지 내부에 정의됩니다 (`TypeAnswerStage.tsx:89`)
- 짝 맞추기는 `모르겠어요`가 없고 다음 버튼이 **`다음 세트`**
- 모바일에서 `이전` **라벨이 사라지고 아이콘만 남습니다** (`hidden sm:inline`)
- 버튼 `h-9 sm:h-12  px-4 sm:px-6  text-xs sm:text-sm`

## 안내문 줄 — `QuizStageHeader`

공유 컴포넌트입니다 (`src/components/quiz/shared/QuizStageHeader.tsx`).

좌·우를 `flex-1`로 균등 분배해서 배지·힌트 유무와 무관하게 **안내문이 정확히 가운데** 옵니다.
목업에서 `padding-left`로 눈대중 맞추면 안 됩니다.

```
[  flex-1 (배지 or 빈칸)  ] [ 안내문 ] [  flex-1 (힌트 or 빈칸)  ]
```

## 문장 순서 맞추기 — 두 영역 순서

**답 영역이 위, 단어 은행이 아래입니다.** 답 영역에 밑줄이 그려지고 타일을 그 위에 놓습니다.

- 타일은 공유 `WordMagnetTile` — `rounded-xl px-3 py-2 text-base shadow-sm border-[#EBE5DE]`
- 조사: `#F4F0EA` 바탕 + `#8A837D` 글자. **조사에도 그림자가 있습니다**
- 일반 단어: 흰 바탕
- 은행에서 꺼낸 자리는 **같은 크기의 회색 빈칸**으로 남아 레이아웃이 흔들리지 않습니다
- 답 영역 간격: 조사 앞 `ml-1`, 단어 앞 `ml-3`
- 은행 `mt-10 min-h-[64px] gap-2.5` — `mt-10`은 `sm:` 변형이 **없어** 모든 폭에서 40px

짝 맞추기 5쌍, 단어 은행 9타일 — **모바일에서도 같습니다.**
