이 패키지는 **학생 대시보드 재편과 학생 내비게이션**만 담고 있습니다. 다른 화면(오답노트·단어장·랜딩·요금제 등)은 포함되지 않습니다.

## 구성

- `snippets/12_student_nav.md` — 무엇을 어느 파일에서 바꿀지 (12-1 ~ 12-5, 체크리스트 포함)
- `design/학생 대시보드 개편.dc.html` — 시안. 브라우저로 바로 열립니다

## 적용 순서

Claude Code에 아래 네 단계를 **하나씩** 붙여넣으세요. 한 번에 전부 시키면 중간부터 품질이 떨어집니다. 각 단계가 끝나면 화면을 직접 확인하고 다음으로 넘어가세요.

### 1단계 — 버그 수정 (P1·P2)

> `handoff-student-dashboard/README.md`와 `snippets/12_student_nav.md`를 읽고, 12-1과 12-2만 적용해줘. 사이드바 "내 클래스"가 학생을 대시보드로 리다이렉트하는 문제를 고치고, `전체 퀴즈`(`/my-quizzes`) 링크를 사이드바와 대시보드의 "전체 보기"에 연결해줘. 레이아웃 변경은 아직 하지 마.

### 2단계 — 내 클래스 화면 신규

> `snippets/12_student_nav.md`의 12-3을 적용해줘. `MyClass.tsx`를 새로 만들고 라우트를 등록해줘. 레이아웃은 `design/학생 대시보드 개편.dc.html`을 브라우저로 열어 시안 **6b**(데스크톱)와 **7b**(모바일)를 보고 맞춰줘.

### 3단계 — 대시보드 재편

> 같은 시안 파일에서 **5a**(데스크톱)·**4a**(모바일)·**3a**(퀴즈 2개 이상)를 보고 `StudentDashboard.tsx`를 재편해줘. "풀어야 할 퀴즈" 섹션은 삭제하고, 히어로가 진행률·다음 유형·액션을 흡수하고, 퀴즈가 2개 이상이면 히어로 아래 얇은 줄로 쌓이게 해줘. 통계 카드 6장은 데스크톱에서 오른쪽 사이드레일 한 장으로 합쳐줘. 클래스 미가입 상태는 12-5와 시안 **7a**·**7d**를 따라줘.

### 4단계 — 전체 퀴즈 정리

> `snippets/12_student_nav.md`의 12-4를 적용해줘. `MyQuizzes.tsx`를 시안 **6c**(데스크톱)·**7c**(모바일)의 테이블형으로 바꿔줘.

## 우선순위 요약

1. **P1 (버그)** — 사이드바 "내 클래스"(`/classes`)가 학생을 대시보드로 리다이렉트. 같은 화면이 두 번 뜨는 원인 → 12-1
2. **P2** — 사이드바에 `전체 퀴즈` 추가 + "전체 보기" 링크 연결. `MyQuizzes.tsx`는 이미 있으나 어디서도 링크되지 않음 → 12-2
3. **P3** — 레이아웃 재편(5a·4a·3a), `MyClass.tsx` 신규(6b·7b), `MyQuizzes.tsx` 정리(6c·7c), 미가입 상태(7a·7d)

## Fidelity

**High-fidelity.** 색·간격·문구가 확정된 목업입니다. 색과 여백은 기존 디자인 시스템 토큰(`bg-card`, `text-muted-foreground`, `border-border`, `text-primary` = `#1E6B47`)을 쓰고, 목업의 인라인 색값은 토큰이 없을 때만 참고하세요. 아이콘은 `lucide-react`, 로고는 저장소의 `/Namu_logo_text_right.png`를 그대로 사용합니다.

## 핵심 원칙 — 화면 역할 분담

| 화면 | 답하는 질문 |
|---|---|
| 대시보드 | 지금 뭘 해야 하나 — 진행 중 퀴즈 **1개**(마감 임박 순) + 다음 퀴즈 줄 + 복습 대기 + 최근 결과 |
| 내 클래스 | 우리 반은 어떤가 — 공지, 반 배정 퀴즈 전체, 같이 배우는 학생, 선생님 |
| 전체 퀴즈 | 내가 받은 퀴즈 전부 — 미완료·완료·점수 |

퀴즈가 몇 개든 히어로는 항상 하나입니다. 나머지는 히어로 아래 얇은 줄로 쌓이고, 4개를 넘으면 3개까지만 보이고 "전체 보기"로 넘깁니다.

`다시 풀기` 버튼은 대시보드에 두지 않습니다 — 내 클래스와 전체 퀴즈에만 둡니다 (12-4 표 참조).
