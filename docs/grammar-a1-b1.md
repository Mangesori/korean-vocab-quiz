# 한국어 문법 목록 (A1–B1)

문장 은행의 문법 태그 후보. TOPIK 1~3급, 세종한국어, 주요 대학 교재(서울대·연세·이화)의
공통분모를 기준으로 정리했다. 교재마다 배치가 다른 항목은 「배치가 갈리는 항목」에 따로 모았다.

`id`는 태그 슬러그로 쓸 값이다. 한글 형태는 표기가 여러 가지라(예: `-어서`/`-아서`/`-아/어서`)
슬러그를 기준으로 삼고 표기는 라벨로만 둔다.

## 배치가 갈리는 항목

교재마다 급수가 다르게 잡히는 것들. 태그를 붙일 때 **자기 교재 기준으로 조정**하면 된다.

| 문법 | 자주 나오는 배치 | 비고 |
|---|---|---|
| `conn-eunikka` -(으)니까 | A1 후반 ~ A2 | -아/어서와 함께 가르치면 A1 |
| `comp-boda` 보다 | A1 후반 ~ A2 | 최상급과 묶으면 A2 |
| `will-gett` -겠- | A1 ~ A2 | 의지만 A1, 추측은 A2로 나누기도 |
| `mod-eun-neun-eul` 관형형 | A1 후반 ~ A2 | 분량이 커서 나눠 가르치는 경우 많음 |
| `banmal` 반말 | A2 ~ B1 | 교재에 따라 아예 안 다루기도 |
| `irregular` 불규칙 | A1부터 분산 | 한 덩어리로 안 잡고 나올 때마다 |
| `report-dago-hada` 간접화법 | B1 ~ B2 | 분량이 커서 나눠 배치 |
| `passive`/`causative` 피동·사동 | B1 ~ B2 | 어휘로 취급하는 교재도 있음 |

## 태그 설계 메모

- **한 문장에 여러 태그가 붙는다.** "밥을 먹**은 후에** 커피를 마시**려고 해요**"는
  `time-eun-hue` + `purp-euryeogo-hada` 둘 다. 단일 태그로 두면 안 된다.
- **레벨은 문법에서 파생시킨다.** 문장에 직접 A2를 붙이지 말고, 붙은 문법 중
  가장 높은 급수를 그 문장의 레벨로 본다. 문법 배치를 바꾸면 문장 레벨이 자동으로 따라온다.
- **불규칙(`irregular`)은 성격이 다르다.** 다른 문법과 층위가 달라서(활용 규칙),
  별도 축으로 두는 편이 낫다.
