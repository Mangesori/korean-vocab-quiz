단계 이름은 세 화면 모두 **학생 / 단어 / 유형·설정**.

```
대기:  ○ 테두리 1.5px #C4BDB6            라벨 13px 600 #6B6460, 묶어서 opacity .45
```

### 2단계 카드 내부 순서 (위 → 아래)

```
1  헤더        좌: 제목 16px bold + "학생명 · 학생 N명 · N개 선택됨" 12.5px
              우: 전체 개수만  "9개 중" / "438개 중"  12px 600 #8A837D

              어휘 보강 → 개수 / 배치 필터 / 다시 뽑기
```

## 13-6 오답 목록 행 (4a)

### 접힌 상태

```
[체크] [단어 14px 700] [유형 칩] [횟수 12px 700]                        [chevron ▾]
       [대표 문장 12.5px #6B6460 — 1줄 ellipsis]
```

- 문장 안 정답 부분만 `<b style="color:#4A443F">`
- 뒤에 ` · 학생명 "학생 답변"` 을 같은 줄에 잇는다
- 받아쓰기 오답은 문장이 없으므로 `뜻 "to fix, repair" · 올리비아 "고치어요"`
- 유형 칩: 첫 유형만 초록(`#E8F1EB`/`#1E6B47`), 나머지는 회색(`#F1EDE7`/`#6B6460`)
- 횟수 2회 이상 `#B4552D`, 1회 `#8A837D`

### 펼친 상태

행 전체를 `background #F4F9F6; border-bottom 1px #E4EDE8`로 감싸고, 헤더 아래 `padding 0 16 16 47px`에 문장 블록을 `gap 14`로 쌓습니다.

```
[문장 13.5px, 정답 부분 초록 bold]
[번역 12px #8A837D]
[학생명 12.5px #6B6460]  ["학생 답변" #C1554A 600]
```

`padding-left 47px` = 체크박스 19px + gap 12 + 여백 16. 문장이 단어 텍스트와 같은 열에서 시작합니다.
