# 16 · 퀴즈 화면 개편

시안: `퀴즈 화면 개편.dc.html`

**적용 대상은 선생님이 쓰는 퀴즈 상세·편집 화면과 색 토큰뿐입니다.**
학생이 푸는 화면(시안 2턴 2a–2e)은 **레이아웃을 바꾸지 않습니다** — 색 토큰(16-1)만 적용됩니다.

적용 순서

```
16-1  색 토큰 치환          3a·3b·3c   ← 가장 넓게 퍼짐, 먼저
16-2  읽기 전용 / 편집 분리  5a·5b      ← 권한 버그 포함
16-3  헤더·아코디언          1a·4a
16-4  문장 순서 타일         1c·6a·6b
16-5  모바일                4b·4c·4d·4e
```

## 16-1 · 색 토큰 치환 (3a·3b·3c)

가장 먼저 하세요. 아래 모든 작업의 바탕입니다.

### 범위를 먼저 확인하세요

`slate-` 로 전체 검색해 목록을 다시 뽑으세요. 확인된 것만 **90곳 이상 · 19개 파일 이상**이고, 검색이 상한에 걸려 실제로는 더 많을 수 있습니다. `src/components/quiz` 바깥(`pages/QuizTake`·`QuizDetail` 등)도 포함됩니다.

### 치환 표

퀴즈 화면은 `slate-*`(청회색)를 직접 쓰고 앱 나머지는 따뜻한 계열입니다. 한 화면 안에서 두 계열이 섞입니다.

| 지금 | 바꿀 값 | 쓰임 |
|---|---|---|
| `slate-50` | `#FAF8F5` | 문제 영역 배경 (가장 많음) |
| `slate-100` | `#F4F0EA` | 보조 배경·비활성 |
| `slate-200` | `#EBE5DE` | 테두리 |
| `slate-300` | `#E3DCD3` | 입력칸 테두리 |
| `slate-400` | `#C4BDB6` | 아이콘 비활성 |
| `slate-500` | `#8A837D` | 보조 텍스트 |
| `slate-600` | `#6B6460` | 본문 보조 |
| `slate-700` | `#4A443F` | 라벨 |
| `slate-800` `slate-900` | `#1A1714` | 본문 |

가능하면 리터럴을 지우고 **기존 CSS 변수**(`--background`·`--border`·`--muted-foreground`·`--foreground`)로 바꾸세요. 다크 모드가 함께 해결됩니다 — 지금 `slate` 리터럴은 다크 모드에서 밝은 회색으로 남습니다.

### 강조색 (3b)

결과 화면에서 원어민 음성이 cyan, 학생 발음이 amber, "듣고 말하기" 배지가 orange입니다. 세 색이 앱 어디에도 없습니다.

```
cyan-*  (원어민 음성)    → 초록 계열  #1E6B47 / 배경 #E8F1EB / 테두리 #C8DED3
amber-* (학생 발음)      → 테라코타   #B4552D / 배경 #FBEFE9 / 테두리 #EBD5C8
orange-100/700 (배지)    → 테라코타 연한 톤  (QuizResultDialog 560 · SpeakingResultStage 111)
```

두 음성을 구별해야 하니 같은 색으로 만들지 마세요 — 초록/테라코타 대비로 갈라 놓습니다.

### 점수 배지 (3c)

`QuizResultsList`가 `green-500`/`yellow-500`/`red-500` 원을 씁니다.

```
80% 이상   #1E6B47  배경 #E8F1EB
50–79%     #B4552D  배경 #FBEFE9
50% 미만   #C1554A  배경 #FBEDEB
```

`--success` 토큰이 이미 있으니 초록만이라도 토큰으로 바꾸세요.

## 16-2 · 읽기 전용 / 편집 분리 (5a·5b)

`FillBlankProblemList.tsx` + `FillBlankEditCard.tsx`.

### 먼저 — 권한 버그

`onDeleteProblem`·`onRegenerateProblem`이 `isEditing`과 무관하게 **두 분기 모두**에 넘어갑니다(285–298줄). 수정하기를 누르지 않았는데 문제가 지워집니다.

### 읽기 전용 (5a) — 내릴 것

값을 **보는** 화면이므로 값을 **바꾸는** 것은 전부 내립니다.

```
내림   카드별 휴지통 · 문제 재생성 · 음성 재생성
       목록 맨 아래 [문제 추가]
       비활성 [저장하기]  ← disabled={isSaving || !isEditing} 로 회색 버튼이 자리만 차지합니다
                            누를 수 없는 버튼은 렌더하지 않습니다
남김   음성 재생 (값을 바꾸지 않습니다)
       [수정하기] · 학생 화면 스위치
⋮ 로   전체 음성 재생성 · 전체 문제 재생성 · 음성 엔진 선택
```

**정답 칸도 뺍니다.** 문장에 정답이 이미 초록으로 박혀 있어(`problem.sentence.split` → `problem.answer`) 바로 아래 정답 칸은 같은 글자를 두 번 보여줍니다. 편집 모드에서는 입력해야 하니 그때 나타납니다.

```
힌트 34% · 번역 나머지   grid-template-columns: 34% 1fr; gap 14px
```

힌트는 짧은 문법 표시(`-아/어 주시다 + 았/었어요`)인데 번역은 문장 전체라 반반으로 나누면 번역만 줄바꿈이 생깁니다.

### 편집 중 (5b)

```
제목 옆   [편집 중] 배지 — #1E6B47 / 배경 #E8F1EB / 테두리 #C8DED3 / 11.5px 700 / radius 8
우측      [수정 취소] + ⋮
숨김      학생 화면 스위치 — 켜면 onToggleStudentPreview(false)로 어차피 꺼집니다
안내 배너  "출제 문장에서 정답이 들어갈 자리에 괄호 ( )를 넣어주세요."
          #F4F9F6 / 테두리 #C8DED3 / 본문 #2C6B4C 12px
```

**칸 순서 — 출제 문장과 미리보기를 붙여 놓습니다.**

```
1  문장 (미리보기)   읽기 전용, 정답이 초록으로 채워진 상태
2  출제 문장          입력칸, ( ) 자리는 #B4552D 700
3  정답 | 힌트        grid-cols-1 sm:grid-cols-2
4  번역 (영어)        전폭 Textarea
```

괄호를 넣는 칸과 그 결과가 세로로 이웃해 있어야 `( )` 규칙이 배너 없이도 읽힙니다.

**저장하기를 하나로.** 지금은 상단 툴바(205줄)와 목록 맨 아래(322줄) 두 곳에 있습니다. 문제가 15개면 둘 다 스크롤 밖입니다.

```
화면 아래 고정 바 하나
  좌  "3개 문제를 고쳤습니다 · 저장하지 않으면 사라집니다"   개수만 #B4552D 700
  우  [수정 취소]  [저장하기]
  background #fff; border 1px #E3DCD3; radius 13; padding 13px 16px
  box-shadow 0 -2px 12px rgba(0,0,0,.04)
```

**재생성 버튼 라벨을 줄이지 마세요.** "음성"으로 줄이면 바로 왼쪽 스피커(재생)와 구별되지 않고, "문제"는 무엇을 하는지 알 수 없습니다. 되돌릴 수 없는 AI 재생성이라 특히 위험합니다.

```
카드 헤더   [문제 재생성]  ← 온전한 라벨, 자주 씀
카드 ⋮      음성 재생성 · 삭제
```

## 16-3 · 헤더와 아코디언 (1a·4a)

### 헤더 압축 (1a)

지금은 문제 편집에 닿기까지 **6단**을 지납니다 — 제목·메타 / 배정 학생 / 단어 / 액션 4개 / 유형 탭 / 툴바.

```
1단  제목 + 메타 한 줄 + 액션
     액션은 [퀴즈 보내기]만 실물 버튼, 라이브·복제·삭제는 ⋮
2단  배정 · 단어 → 아코디언 두 개 (기본 접힘)
3단  유형 탭
```

### 아코디언 펼친 상태 (4a)

접힌 줄이 **그대로 헤더가 되고** 아래로 내용이 열립니다 — 줄이 사라지거나 위치가 바뀌지 않습니다.

```
배정  펼치면  학생 칩 목록 + [학생 추가]
단어  펼치면  단어 칩 15개 + [단어 편집] [단어 추가]
      칩: 12.5px 600 / 배경 #F4F9F6 / 테두리 #DCE9E2 / radius 8 / padding 7px 11px
      display flex; flex-wrap wrap; gap 6
```

**단어를 세트로 묶지 마세요 — 지금 데이터로 불가능합니다.** `QuizWords`가 받는 것은 `words: string[]`, 이름만 나열된 목록입니다. 각 단어가 몇 번 세트인지가 어디에도 없습니다. 문제(`problemSets`)에는 세트가 있지만 단어에는 없습니다. **평평한 칩 15개**로 두세요.

> 나중 제안: 단어 데이터에 세트 번호를 넣으면(DB 컬럼 + 퀴즈 생성 시 함께 저장) 문제 목록과 대조가 됩니다. 화면 작업과는 별건입니다.

## 16-4 · 문장 순서 타일 (1c·6a·6b)

`WordMagnetEditCard.tsx`. 데스크톱·모바일이 `splitAt`·`mergeLeft` 하나를 공유합니다 — 다른 것은 버튼에 닿는 방법뿐입니다(데스크톱 `hidden group-hover:flex`, 모바일은 16-5의 하단 시트).

### 안내문 (1c)

타일 편집 안내가 **줄마다 반복**됩니다("집 클릭 = 조사 지정…"). 카드 위 **한 번만** 두세요.

### 나누기 (6a) — 두 단계

```
1  타일 선택 → 가위 아이콘
2  타일이 글자 단위로 벌어지고 글자 사이에 막대가 생김
   막대 4px × 26px / radius 2 / 후보 #B7D3C4 / 지금 누를 자리 #1E6B47 + 3px 링
   컨테이너 border 1.5px #1E6B47 / 배경 #F4F9F6 / radius 10 / padding 5px 7px
   끝에 [취소] 11px #6B6460
3  막대를 누르면 그 자리에서 갈라짐
```

`날에는` 에서 첫 막대 → `날` + `에는`, 둘째 막대 → `날에` + `는`. 자리를 고르기 전까지 아무것도 바뀌지 않습니다.

**제안 — 오른쪽 조각의 조사 표시를 유지하세요.** 지금은 나누면 항상 꺼집니다(`isParticle: false`, 79줄). 조사를 떼어내려고 나누는 경우가 대부분이니 켜 두면 탭 두 번이 한 번이 됩니다.

한 글자 타일에는 나누기가 없습니다 (`t.content.length > 1`).

### 합치기 (6b) — 즉시

중간 단계 없이 **바로 앞 타일과 붙습니다**. 그래서 누르기 전에 무엇과 붙는지 보여야 합니다.

```
선택하면  두 타일을 점선으로 함께 감쌈
          border 1.5px dashed #1E6B47 / 배경 #F4F9F6 / radius 12 / padding 4
          두 타일 사이에 고리 아이콘 22px 원 #1E6B47 (margin 0 -4px, z-index 1)
```

색은 **앞 타일**을 따릅니다(`isParticle: items[i-1].isParticle`). 흰 + 노란을 합치면 흰 타일입니다.

**제안 — 되돌리기를 붙이세요.** 합치기는 확인 없이 적용되는데, 잘못 합치면 나누기로 되돌려야 하고 그건 3탭입니다(나누기 → 자리 고르기 → 조사 다시 켜기). 방금 한 동작 하나만 되돌리는 버튼이면 1탭입니다.

```
합친 뒤 안내 + [되돌리기]  배경 #F4F9F6 / 테두리 #C8DED3 / radius 9
```

첫 타일에는 합치기가 없습니다 (`i > 0`).

## 16-5 · 모바일 (4b·4c·4d·4e)

`QuizDetail.tsx`에서 `sm:` 접두사가 붙은 곳은 **유형 탭 하나뿐**입니다.

### 이미 되어 있는 것 — 손대지 마세요

```
유형 탭        grid grid-cols-2 w-full sm:w-auto sm:inline-flex   → 모바일 2열
FillBlankEditCard  flex-col … sm:flex-row / sm:hidden / hidden sm:inline-flex
```

### 실제로 없는 것

**헤더와 액션 행** — 제목·메타·버튼 4개(보내기·라이브·복제·삭제)에 `sm:`이 하나도 없습니다.

```
제목    두 줄 허용 (예: "2.24 지희 – 주막 이야기 5")
액션    [퀴즈 보내기] 전폭 · 높이 44px · radius 11
        나머지(라이브·복제·삭제)는 44×44 ⋮ 버튼
```

**정답·힌트 행이 `grid grid-cols-2` 고정**(`FillBlankEditCard` 192줄, `sm:` 없음) — 375px에서 두 입력칸이 각각 160px로 좁아집니다.

```
grid-cols-2 → grid-cols-1 sm:grid-cols-2
```

### 읽기 전용 (4d)

```
제목 + "세트 1 · 5문제"
[수정하기] 전폭 44px + 44×44 ⋮
[학생 화면으로 보기] 스위치 행 따로       ← 제목 옆에 붙이면 375px에서 제목이 밀립니다
문제 카드 — 전부 펼침
  번역만 [번역 보기]로 접음
```

문제를 확인하려고 여는 화면이니 **전부 펼쳐 둡니다.** 하나씩 눌러 열게 하면 확인 자체가 일이 됩니다. 접는 것은 번역뿐입니다.

### 편집 중 (4c·4e)

```
문장 순서 타일 조작 → 하단 시트
  지금 팝오버는 화면 밖으로 나갈 수 있고, 모바일에는 호버가 없어
  hidden group-hover:flex 로는 버튼에 닿을 방법이 없습니다 (240·250줄)
  탭 → 하단 시트가 유일한 경로입니다
드래그 → 길게 누르기
문법 배지가 본체와 떨어지지 않도록 두 조각을 한 inline-flex 로 묶기
⋮ 안: ElevenLabs 선택 · 전체 재생성
```

## 16-6 하지 말 것

- **학생이 푸는 화면의 레이아웃을 바꾸지 마세요.** 색 토큰(16-1)만입니다. 시안 2턴은 기록용입니다.
- **읽기 전용에서 삭제·재생성을 열어두지 마세요.**
- **비활성 저장하기를 렌더하지 마세요.**
- **저장하기를 두 곳에 두지 마세요.** 하단 고정 바 하나.
- **재생성 라벨을 한 단어로 줄이지 마세요.** 되돌릴 수 없는 동작입니다.
- **단어를 세트로 묶지 마세요.** 데이터에 세트 번호가 없습니다.
- **모바일 읽기 전용에서 문제를 접지 마세요.** 번역만 접습니다.
- **유형 탭을 가로 스크롤로 바꾸지 마세요.** 이미 2열 그리드로 되어 있습니다.
- **정답 칸을 읽기 전용에 두지 마세요.** 문장에 이미 박혀 있습니다.
