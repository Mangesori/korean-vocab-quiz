## 14-0 먼저 고칠 버그 — `Infinity%`

평균 점수 표시에 `Infinity%`가 뜹니다. 원인은 제출 0건이 아닙니다 (`classResults.length > 0` 가드는 이미 있음).
**`score / total_questions`에서 `total_questions`가 0인 결과 행**입니다.

```
Classes.tsx            192행 부근
TeacherDashboard.tsx   262행 부근
AdminDashboard.tsx     같은 식
학생 대시보드           같은 식
```

평균 점수를 카드에서 빼도(5b·5e) 위 나머지 화면에 남으니, 집계 전에 `total_questions > 0` 필터를 넣으세요.

## 14-1 5e · 내 클래스 카드  — 마크업만

`ClassStats`에 값이 모두 있습니다. 쿼리 변경 없음.

**바꿀 것**

| 지금 | 바꿀 것 |
|---|---|
| "배정 퀴즈" | **"배정된 퀴즈"** |
| 평균 점수 | **제거** (1:1 + 배정 1개면 무의미, `Infinity%` 발생 지점) |

| 초대 코드만 큼직하게 | 라벨 "초대 코드" + 값 + 복사 아이콘, 다른 행과 같은 크기 |
| 제목=클래스 이름(별명) | **1:1은 학생 실명을 제목**, 별명을 부제로 |

**행 구조**

```
아바타 34px + [제목 15px 700 / 부제 11.5px #8A837D]
─ border-top 1px #F2EDE7, padding-top 13 ─
라벨 12px #6B6460          값 13px 700          ← gap 9, 3행
초대 코드                   UQ2NGW 12.5px 700 #1E6B47 letter-spacing .06em + 복사 13px
[클래스 열기]  초록, radius 9, padding 10px 0, 가운데
```

- 1:1 부제: `1:1 · 오스틴` / 그룹 부제: `학생 6명`
- 그룹 카드 3행: 배정된 퀴즈 / **미제출**(`#B4552D`) / 초대 코드
- 마지막 활동이 없으면 그 행 대신 `아직 활동 없음` 한 줄만
- 그룹은 아바타 자리에 users 아이콘 17px

## 14-2 5c · 내 퀴즈 행  — 마크업만 (배치 변경)

아이콘 4개는 지금 호버 시 나오는 것과 **동일한 동작**입니다. 열 배치만 바꿉니다.

```
grid-template-columns: 52px 1fr 130px 190px 90px 116px 150px;  gap: 14px
                       레벨  제목 분량   배정   제출  만든날짜  아이콘(헤더 라벨 없음)
행 padding 14px 22px
```

- **날짜를 왼쪽으로 당기고 아이콘 열을 맨 오른쪽에 150px 고정.** 폭이 고정이라 호버 시 다른 열이 밀리지 않습니다.
- 아이콘은 `opacity .3`으로 **상시 표시**, 호버 행만 `opacity 1`. 있는 걸 알 수 있게 하는 게 목적입니다.
- 아이콘 4개 순서·`gap 14`: 공유(send) / 결과(bar-chart) / 배정(user-plus) — 모두 `stroke #4A443F 1.9` / 삭제(trash) `stroke #C1554A`
- 아이콘 열 정렬: `display flex; justify-content flex-end; gap 14`

**미배정 행은 다릅니다**

```
배정 열   "배정 안 됨"  #B4552D 600
제출 열   "—"  #B9B2AB
행 배경   #FDFCFA,  레벨 칩 #F1EDE7/#7C756F,  제목 #4A443F
아이콘 열 → [배정하기] 초록 버튼 11px 700 radius 8 padding 6 11  +  삭제 아이콘(opacity .3)
```

결과·공유 아이콘은 결과가 없는 퀴즈에서 의미가 없으니 숨깁니다. 미배정이 46개라 그 행에서 할 일은 하나입니다.

## 14-3 5b · 최근 활동 클래스 (레일)  — 쿼리 확장

**% 를 없앱니다.** 무슨 %인지 라벨이 없고 `Infinity%`가 뜨는 자리입니다.

```
행:  아바타 24px + [이름 12.5px 600 / "어제 제출" 10.5px #8A837D]  + 칩(있을 때만)
칩:  10.5px 700, radius 6, padding 4px 7px
     확인 대기  → #E8F1EB / #1E6B47
     미제출 N   → #FBEFE9 / #B4552D
하단: [내 클래스 27개 →]  [＋ 새 클래스]  (border-top 1px #F2EDE7, padding-top 12)
```

**칩은 있을 때만 렌더합니다.** 아무 표시가 없으면 처리할 게 없다는 뜻 — 배지를 항상 채우면 다시 읽어야 하는 숫자가 됩니다.

- "확인 대기"는 `unviewed`에 이미 있음
- **클래스별 미제출은 구현 필요**: `recentActiveClasses`는 `avgScore`·`lastActivity`만 만듭니다. `Classes.tsx`가 `pendingCount`를 계산하므로 같은 로직을 옮기세요.
- 부제는 `2시간 전` → **`어제 제출`**처럼 무엇이 있었는지까지 씁니다

## 14-4 5f · 클래스 상세  — 마크업 + 일부 신규

**통계 3분할 카드를 없애고 헤더 한 줄로 접습니다.** 담긴 정보가 세 줄인데 화면 상단을 다 쓰고 있습니다.

```
[클래스명 22px 700]  [연필 15px #A29B94]
1:1 · 오스틴 | 퀴즈 1개 | 학생 1명 | 최근 배정 8월 17일     ← 12.5px #6B6460, 구분자 "|" #D8D1C8
                                                            숫자만 #1A1714 bold

우측 정렬:  [초대 코드 UQ2NGW ⧉]  [공지사항]  [＋ 퀴즈 배정 초록]  [⋮]
            흰 배경 + border 1px #E3DCD3 + radius 11 + padding 10px 14px
```

**클래스 삭제는 `⋮` 안으로.** 되돌릴 수 없는 동작을 배정 버튼 옆에 붉게 두면 오조작 위험만 있습니다.
현재는 네이티브 `confirm()`이므로 `AlertDialog`로 바꾸세요 — 같은 파일의 할당 삭제가 이미 그걸 씁니다.

**본문 2열** `1fr 320px; gap 20`

왼쪽 — 배정된 퀴즈 테이블
```
grid-template-columns: 52px 1fr 120px 100px 116px
                       레벨  제목  분량   제출   배정일(우측정렬)
제목 셀 = 제목 13.5px 600 + 단어 칩 대신 부제 11.5px #8A837D 1줄 ellipsis
         "높다 · 낮다 · 많다 · 적다 · 크다 +10"
하단 바: "이 클래스에 배정된 퀴즈만 표시합니다."   [＋ 퀴즈 배정]
```

오른쪽 레일
```
학생 카드     학생 N명 + [전체 보기 →]
              행: 아바타 28px + 이름 12.5px + "8월 17일 가입 · 마지막 활동 7일 전" 10.5px + chevron
              하단: "초대 코드 UQ2NGW를 학생에게 보내면 이 클래스에 들어옵니다."
이 학생에게    [오답 복습 퀴즈 만들기]  [어휘 보강 퀴즈 만들기]
              border 1px #E7E1DA, radius 10, padding 11px 13px, 아이콘 14px
```

오답·어휘 보강 진입을 여기 두는 이유 — 두 기능은 "이 학생"이 정해져야 시작되므로 클래스 상세가 가장 자연스러운 입구입니다.

**구현 필요**
- **＋ 퀴즈 배정** — 이 화면에 배정 경로가 없습니다(빈 상태 문구가 "퀴즈 상세 페이지에서 배정해보세요"). 퀴즈를 고르는 역방향 선택이 필요합니다.
- **학생별 마지막 활동** — 지금은 클래스 단위로만 계산됩니다.
- `전체 퀴즈 보기` / `전체 학생 보기`는 `ClassAssignedQuizzes` · `ClassStudents`가 이미 있으니 그대로 연결.

## 14-6 5a · 미제출 아코디언

지금 카드는 20명인데 3명만 보이고, 링크는 클래스 목록으로 갑니다.

```

       우측에 [방치 기간 ⌄]
행     아바타 26px + [이름 13px / 퀴즈명 11.5px #8A837D] + 방치 배지 + [재알림] [회수]
```

**구현 상태**
- 목록·방치 일수는 `pendingList`에 이미 있습니다 — `slice(0, 3)`만 풀면 됩니다.
- **회수** = `ClassDetail`의 `handleDeleteConfirm`이 하는 `quiz_assignments.delete()`와 같은 동작. mutation을 재사용하고 **문구를 "할당 삭제"와 통일**하세요.
- **재알림 / 모두 재알림은 신규**: 알림을 다시 보내는 경로가 없습니다(현재 알림은 제출 시 생성).
- 방치 기간 정렬은 클라이언트에서 가능.

**대안** (5a 대신 갈 수 있는 길, 노트에 적힌 것)

## 14-8 하지 말 것

- **평균 점수를 다시 넣지 마세요.** 라벨 없는 %는 무슨 값인지 알 수 없고, `total_questions = 0` 필터 없이는 `Infinity%`가 뜹니다.
- **아이콘을 호버에서만 나타나게 하지 마세요.** 있는 줄 모릅니다. `opacity .3` 상시 → 호버 시 1.
- **아이콘 열 폭을 가변으로 두지 마세요.** 호버 시 다른 열이 밀립니다.
- **미배정 행에 결과·공유 아이콘을 두지 마세요.** 결과가 없습니다.
- **링크 공유 탭의 익명 응시 스위치를 지우지 마세요.**
- **클래스 삭제를 배정 버튼 옆에 붉게 두지 마세요.** `⋮` 안으로.
- 클래스 카드에서 초대 코드를 가장 크게 두지 마세요. 이미 가입한 클래스에서는 거의 쓰지 않는 정보입니다.
