6문장 순서 타일 — 나누기 · 합치기 누르기 전 / 후

WordMagnetEditCard의 splitAt·mergeLeft입니다. 두 동작의 성격이 다릅니다 — 합치기는 한 번에 끝나고(앞 타일과 즉시 붙음), 나누기는 두 단계입니다(어디를 자를지 골라야 함). 그래서 나누기만 중간 상태가 있습니다.

390px로 그렸지만 내용은 데스크톱도 같습니다. 글자 사이 막대를 골라 자르는 방식과 앞 타일과 붙는 규칙은 splitAt·mergeLeft 하나를 공유합니다. 다른 것은 버튼에 닿는 방법뿐입니다 — 데스크톱은 타일에 마우스를 올리면 가위·고리가 나타나고(hidden group-hover:flex), 모바일은 호버가 없어 4e의 하단 시트를 씁니다. 데스크톱에서 바뀌는 것은 1c의 안내문 정리와, 여기서 제안한 조사 표시 유지 · 되돌리기 두 가지입니다.

3 자주

＋ 문제 추가

소스 확인 결과 정정. FillBlankEditCard는 sentence·answer 두 필드만 저장하고, 맨 위 문장 블록은 sentence의 ()를 answer로 갈아 끼운 같은 필드의 읽기용 표시입니다 — 저장되는 문장이 두 개인 것은 아닙니다. 따라서 마이그레이션은 필요하지 않습니다.

그래도 두 필드가 어긋날 수는 있습니다 — sentence에 ()가 없거나 위치가 틀리면 빈칸이 사라지고, answer만 고치면 문장은 그대로입니다. 드래그로 빈칸을 지정하면 그 어긋남이 생길 수 없습니다. 편집 모드에서 같은 문장이 표시 1줄 + 입력 1줄로 두 번 나오는 것도 없어집니다.

힌트가 비어 있으면 힌트 없음 배지가 붙습니다(3번 문제처럼). 지금은 빈 입력칸이라 의도적으로 비운 것인지 빠뜨린 것인지 알 수 없습니다. 번역은 회색 한 줄로 내려 문제당 높이가 절반이 됩니다.

1c문장 순서 맞추기 편집. 타일 편집 안내가 지금은 줄마다 반복됩니다("집 클릭 = 조사/어미 토글 · 마우스를 올려 나누기…"). 상단 안내 한 번으로 옮기고, 타일 조작은 선택한 타일 위에 작게 띄웁니다.

"정답 문장 (학생에게는 숨겨짐)" 라벨과 "칩 클릭 = 조사/어미 토글 · 마우스를 올려 나누기(✂) / 합치기(🔗)" 안내가 WordMagnetEditCard 안에 있어 문제 카드마다 반복됩니다(5문제면 5번). 이 화면은 선생님만 보므로 매 문제마다 붙일 필요가 없습니다. 문장·번역·타일이 한 블록으로 붙어 한 문제가 세 줄에 들어갑니다.
